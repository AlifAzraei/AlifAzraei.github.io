# MAA — Modern Finance Portfolio

A responsive modern portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Included files
- `index.html` — website structure and content
- `style.css` — modern navy/blue design and responsive layout
- `script.js` — mobile navigation and small interactions
- `assets/` — place your own profile photo and CV PDF here

## Before publishing
1. Replace `MAA` with the display name you want to use.
2. Replace `your.email@example.com` with your professional email.
3. Replace the LinkedIn `href="#"` links with your actual LinkedIn URL.
4. Add your professional portrait as `assets/profile.jpg`. In `index.html`, uncomment the `<img>` line inside `.portrait-frame` and remove the `.portrait-placeholder` block.
5. Add your CV PDF as `assets/your-cv.pdf`.
6. Replace all three sample project descriptions and GitHub links with your real project repositories or published dashboards. These cards are placeholders, not claims of completed work.
7. Confirm the experience metrics and job details are accurate before publishing.

## Preview locally
Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public repository, e.g. `finance-portfolio`.
2. Upload the files and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.

Expected URL: `https://maazraei01.github.io/finance-portfolio/`
